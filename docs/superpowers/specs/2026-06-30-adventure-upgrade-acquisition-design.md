# 冒险模式强化获得规则方案

## Summary
本文用于记录冒险模式 `3选1` 强化系统中，已经确认的“强化获得规则”和“触发顺序规则”。
当前范围只覆盖玩家在一局 12 关线性冒险中，什么时候获得强化选择机会、何时弹窗、何时生效，以及多个触发条件重叠时的顺序。
候选池生成、花色分布、稀有度控制、重复强化规则、刷新规则和数值平衡，不在本文当前范围内，后续讨论通过增补本文继续收敛。

## Current Adventure Structure
- 冒险为 `12` 关纯线性流程。
- 玩家打完一关后进入下一关。
- 全局使用共享生命值。
- 中途一旦失败，本次冒险结束，并从第 `1` 关重新开始。

## Upgrade Grant Rules
### 1. 开局强化
- 在第 `1` 关开始前，玩家先获得 `1` 次 `3选1` 强化。
- 玩家完成选择后，所选强化立即生效，再进入正式战斗流程。

### 2. 关卡胜利强化
- 每赢得 `1` 关，玩家获得 `1` 次 `3选1` 强化。
- 该强化在“关卡胜利后立刻弹出”。
- 玩家完成选择后，所选强化立即生效。
- 强化生效后，才继续执行该关的后续结算流程。

### 3. 大收牌强化
- 当一次收牌满足“大收牌”条件时，玩家立即获得 `1` 次 `3选1` 强化。
- “大收牌”条件定义为：
  - 本次收牌中，不计算首尾两张牌。
  - 若中间收走的牌数 `>= 5`，则视为触发一次大收牌奖励。
- 等价理解：
  - 一次总共收走至少 `7` 张牌。
  - 其中首尾两张只参与收牌结果，不参与大收牌判定计数。
- 大收牌强化在触发时立刻弹出。
- 玩家完成选择后，所选强化立即生效，再继续当前关卡剩余流程。

### 4. 大收牌奖励次数
- 大收牌奖励不设上限。
- 同一关内可多次触发。
- 同一局内可多次触发。

## Trigger Timing And Resolution Order
### 1. 强化一律即时选择、即时生效
- 所有来源的 `3选1` 强化，都是当场弹出、当场选择、当场生效。
- 不做“战后统一结算强化”。
- 不做“累计到库存后手动领取强化”。

### 2. 大收牌触发时的结算位置
- 当一次收牌完成并确认满足大收牌条件后，立刻弹出 `3选1` 强化。
- 本次强化选择完成并生效后，再继续当前关卡中的后续流程。

### 3. 关卡胜利触发时的结算位置
- 当本关已确认胜利后，先弹出 `3选1` 强化。
- 该强化选择完成并生效后，再执行本关结算。
- 本关结算结束后，再进入下一关。

### 4. 大收牌与关卡胜利同时发生时的顺序
- 若某次大收牌同时直接导致本关胜利，则按以下固定顺序处理：
  1. 先触发大收牌强化。
  2. 再触发关卡胜利强化。
  3. 最后执行本关结算。
- 这样可以保持“动作内触发”先于“关卡层触发”的顺序一致性。

## Candidate Pool Rules
### 1. 不允许重复强化
- 单局内已经获得过的强化，不得再次出现在后续任何一次 `3选1` 候选中。
- 这里的“不允许重复”按“强化唯一 ID”判断，而不是按花色、稀有度或文本相似度判断。
- 玩家一旦选中过某个强化，该强化就从本局剩余候选池中永久移除。
- 该限制同时适用于：
  - 开局强化
  - 关卡胜利强化
  - 大收牌强化
- 本规则只限制“已获得的强化不可再次出现”。

### 2. 未选中的候选允许再次出现
- 若某次 `3选1` 中出现了三个候选，玩家只选择其中一个，则另外两个“未被选中但也未获得”的强化，不会因为本次展示而被移出候选池。
- 换句话说：
  - 已选中的强化，从本局候选池中永久移除。
  - 未选中的强化，后续仍然允许再次进入候选池。
- 本规则确保“是否移出候选池”的判断标准只有一个：
  - `玩家是否已经实际获得该强化`

### 3. 四个花色混合进入候选池
- 候选池采用 `4` 个花色混抽。
- 不做“单局先锁定某个花色”或“按当前花色路线只出对应强化”的限制。
- 每次生成 `3选1` 候选时，四个花色的强化都可以参与本次抽取。

### 4. 单次三候选的花色组成不做限制
- 同一次 `3选1` 中，三个候选的花色分布完全按随机结果决定。
- 不要求三个候选覆盖多个花色。
- 不要求同一次候选中必须出现不同花色。
- 允许出现以下任意情况：
  - `3` 个候选全部来自同一花色
  - `2` 个候选来自同一花色，另 `1` 个来自其他花色
  - `3` 个候选分别来自不同花色
- 只要候选本身满足“未被本局获得过”的约束，就视为合法候选组合。

### 5. 同一次三候选内不允许重复同一强化
- 同一次 `3选1` 中，三个候选必须对应 `3` 个不同的强化唯一 ID。
- 不允许在同一组候选里出现两个或三个完全相同的强化。
- 换句话说：
  - 候选之间允许同花色。
  - 候选之间允许同稀有度。
  - 但候选之间不允许是同一个强化实体的重复副本。
- 该规则只限制“同一次候选内部不能重复同一强化”。
- 它不影响“某个未选中的强化在未来其他次 `3选1` 里再次出现”的规则。

## Rarity Rules
### 1. 稀有度基础权重按关卡区间决定
- 强化候选的稀有度，先根据当前所处的关卡区间，确定一个“基础权重”。
- 当前已经确认的基础权重如下：

| 关卡区间 | 普通 | 稀有 | 传说 |
|---|---:|---:|---:|
| `1-4` 关 | `70` | `25` | `5` |
| `5-8` 关 | `50` | `35` | `15` |
| `9-12` 关 | `30` | `45` | `25` |

- 该规则用于保证前期更稳定、中期开始抬升、后期更容易出现高稀有强化。

### 2. 所有触发来源共用同一套稀有度权重
- 不论本次 `3选1` 强化来自：
  - 开局强化
  - 关卡胜利强化
  - 大收牌强化
- 都统一使用“当前关卡区间对应的基础稀有度权重”。
- 不对不同触发来源做额外稀有度修正。
- 也就是说：
  - 开局强化不额外压低高稀有概率。
  - 大收牌强化不额外提高高稀有概率。
  - 关卡胜利强化也不使用单独权重。

### 3. 单次三候选按权重纯随机组成
- 每次生成 `3选1` 候选时，三个候选都按当前关卡区间对应的稀有度权重，分别独立进行随机。
- 不添加任何强制组成规则。
- 这意味着以下情况都允许自然出现：
  - `3` 个都是普通
  - `2` 个普通加 `1` 个稀有
  - `1` 个普通加 `2` 个稀有
  - `3` 个都是稀有
  - `1` 个传说配其余任意组合
  - 甚至 `3` 个都是传说
- 只要结果符合权重随机结果，就视为合法候选组成。
- 不做以下额外控制：
  - 不保底至少出现 `1` 个非普通
  - 不限制单次最多出现 `1` 个传说
  - 不限制三张候选必须覆盖多个稀有度层级
  - 不因为结果“看起来太欧或太非”而重抽

### 4. 当前稀有度候选不足时按预设顺序补位
- 若某次随机结果命中了某个稀有度，但该稀有度在当前剩余候选池中已经没有可用强化可抽，则本次抽取不作废，也不整组重抽。
- 此时应按固定优先顺序，从其他仍有可用强化的稀有度中补位。
- 补位顺序固定为：
  - 命中 `传说` 时：`稀有 -> 普通`
  - 命中 `稀有` 时：`普通 -> 传说`
  - 命中 `普通` 时：`稀有 -> 传说`
- 例子：
  - 本次结果抽到 `传说`，但当前没有任何可用传说强化，则改为从可用的 `稀有` 中抽。
  - 若当前 `稀有` 也没有可用强化，则继续改为从可用的 `普通` 中抽。
  - 本次结果抽到 `普通`，但当前没有任何可用普通强化，则改为从可用的 `稀有` 中抽。
  - 若当前 `稀有` 也没有可用强化，则继续改为从可用的 `传说` 中抽。
- 不因某个稀有度耗尽而整组重抽，只在当前候选位上按上述顺序补位。

## Candidate Generation Flow
### 1. 构建本局当前可用池
- 每次准备生成一次 `3选1` 时，先构建“本局当前可用池”。
- 本局当前可用池 = 全部强化 - 本局已经获得过的强化。
- 本局未选中的候选，不从可用池中移除。

### 2. 按当前关卡确定稀有度权重
- 根据当前所处的关卡区间，选择对应的基础稀有度权重：
  - `1-4` 关
  - `5-8` 关
  - `9-12` 关
- 所有来源的强化触发，都共用这一步得到的权重。

### 3. 逐个生成候选位
- 一次强化弹窗默认目标为生成 `3` 个候选。
- 三个候选位按相同规则逐个生成。
- 每个候选位之间没有“必须覆盖不同花色”或“必须覆盖不同稀有度”的额外约束。

### 4. 每个候选位的生成顺序
- 每个候选位按以下顺序生成：
  1. 先按当前关卡权重随机命中一个目标稀有度。
  2. 检查该稀有度在当前剩余可用池中是否还有可抽强化。
  3. 若有，则从该稀有度对应的可用强化中随机抽取 `1` 个具体强化。
  4. 若没有，则按本文已确认的稀有度补位顺序切换到其他稀有度继续抽取。
  5. 若抽中的具体强化已经出现在本次同一组候选中，则重新抽取具体强化，直到本组候选 ID 不重复，或该档可用强化已被本组候选占满。

### 5. 花色抽取方式
- 在某个候选位已经确定“要从哪个稀有度抽取”之后，从该稀有度下全部可用强化中随机抽取具体强化。
- 花色不单独做权重控制。
- 四个花色在该稀有度下统一参与随机。

### 6. 同组去重规则
- 同一次 `3选1` 中，三个候选必须是三个不同的强化 ID。
- 如果某个候选位命中了已经出现在本组前面候选里的强化，则该候选位继续重抽具体强化。
- 若当前目标稀有度下，剩余可用强化数量不足以满足“本组不重复”，则可以切换到该候选位允许的后续补位稀有度继续补充。

### 7. 剩余可用强化少于三个时的展示规则
- 若本局当前可用池中的强化总数已经少于 `3` 个，则本次强化弹窗只展示剩余全部可用强化。
- 不强行补满到 `3` 个。
- 不因为数量不足而生成重复候选。
- 不因为数量不足而临时放开“已获得强化不可再次出现”的限制。

### 8. 选择后的可用池更新
- 玩家本次实际选中的强化，在获得后立即从本局后续可用池中永久移除。
- 本次未被选中的其他候选，不移除，后续仍然允许再次出现。

## Design Intent
- 保证玩家每局都有稳定成长：开局一次、每关胜利一次。
- 用大收牌奖励鼓励玩家主动追求高光操作，而不是只打保守过关。
- 强化必须即时生效，确保玩家能在危险局面中，依靠当前刚拿到的强化直接影响后续战斗结果。
- 大收牌奖励不设上限，允许局内出现连续成长和爆发局面，形成更强的构筑爽感。

## Out Of Scope
以下内容尚未在本文定案，后续统一补充到同一文档中：

## Decisions Locked In This Revision
- 开局提供 `1` 次 `3选1` 强化。
- 每次关卡胜利提供 `1` 次 `3选1` 强化。
- 大收牌条件为“中段牌数 `>= 5`”。
- 大收牌奖励无上限。
- 所有强化均为立刻弹出、立刻选择、立刻生效。
- 若大收牌同时带来关卡胜利，则顺序为“大收牌强化 -> 胜利强化 -> 本关结算”。
- 单局内已获得过的强化，不允许再次进入后续候选池。
- 单次展示但未被选中的强化，后续允许再次进入候选池。
- 候选池采用四个花色混抽。
- 单次 `3选1` 的花色组成纯随机，不做任何覆盖或去重限制。
- 同一次 `3选1` 中，三个候选必须是三个不同的强化 ID。
- 稀有度基础权重按关卡区间分为 `1-4 / 5-8 / 9-12` 三段。
- 所有触发来源共用同一套当前关卡区间稀有度权重，不做额外修正。
- 单次 `3选1` 的三个候选，按权重独立纯随机生成，不做任何强制组成或保底控制。
- 当命中的稀有度在剩余池中不足时，按预设顺序补位，不整组重抽。
- 候选池生成时，先按关卡抽稀有度，再从对应稀有度和四花色混合池中随机抽具体强化。
- 若本局剩余可用强化少于 `3` 个，则只展示剩余全部可用强化，不强行补满。
