# 软糖触手飘浮待机示例

这是未接入游戏的示例资源，用于预览“触手飘浮”的待机方向。

- 源参考：`../idle/processed/idle-1.png` 到 `idle-12.png`
- 输出帧：`frames/idle_tentacle_float-01.png` 到 `idle_tentacle_float-12.png`
- 播放建议：12 帧循环，0.12 秒/帧
- 动作意图：头部基本稳定，触手根部小幅移动，触手末端左右飘浮并轻微上浮，下半部带一点弱流光
- 未修改：`resources/character_avatars/jellyfish.tres` 和现有 `idle/processed` 帧
